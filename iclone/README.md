# iCLONE OS — app charter

iCLONE OS is the iNFT desktop app: Hermes Desktop underneath, iCLONE soul on
top — 3D iNFT stage, frosted dock, EconomyOS (Virtuals `acp`), Privy wallet
login, god-name identity. Its tree was imported once from
[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)
(MIT) at the commit recorded in `iclone/UPSTREAM_BASE`.

## Two tracks, never merged

1. **Track A — the runtime.** `~/.hermes/hermes-agent` follows Nous Research
   `main` through `hermes update`. Before an update is applied, the app checks
   it against our runtime contract (`iclone/contract/`): the lock generated
   from our code is verified against the target's OpenRPC, and a RED verdict
   stops the update in Electron main until the app is fixed forward.
2. **Track B — this app.** The code here is ours. Upstream is a reference,
   never a merge source: an upstream change we want is studied, then written
   again in our design, and recorded in the adoption ledger
   (`iclone/upstream/adoption/`) with `Adoption:` / `Adopts-Upstream:` commit
   trailers.

## Discipline (non-negotiable)

1. Everything ours that is not app code lives under `iclone/`.
2. The contract lock is generated by `iclone/contract/extract.mjs`, never
   edited by hand; a lock diff is a reviewed change.
3. `iclone/UPSTREAM_BASE` records the import origin only. It never moves.
4. Keep the MIT `LICENSE` and Nous copyright intact.
