## Agent Coordination

Each agent has a defined role. Do not duplicate work.

| Agent | Responsibility | When to use |
|---|---|---|
| **SPEC-DRIVEN** | Context, specs, coordination | Start and end of every feature |
| **Rider** | Multi-agent orchestration | Complex, multi-file features |
| **hm-engineer** | Code validation | Before any PR |
| **hm-designer** | UI/UX validation | Before shipping any interface |
| **hm-qa** | Tests and edge cases | After implementation |
| **hm-security** | Security audit | Before any deploy |
| **hm-deploy** | Infrastructure gate | Final deploy |

**Standard sequence for a feature:**
```

→ Rider (orchestration) → hm-engineer (validation)
→ hm-designer (if UI) → hm-qa → hm-security
→ hm-deploy → SPEC-DRIVEN:review → SPEC-DRIVEN:train
```
